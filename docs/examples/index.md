# Examples

See how complete workflows are built, so you can build your own. Each page takes one workflow from
the [AGL-workflows](https://github.com/jashioq/AGL-workflows) repository, shows how to get it and
run it, then walks through its main parts with excerpts of its code.

- [`implement_and_review`](implement_and_review.md) - Implements a request with Claude Code, then
  has Codex review the work and fixes what it finds, for up to three reviews.
